# University laboratory works

Практические задания по Python и Django (лабораторные №1–7).

## Каталоги

| Каталог | Тема |
|---------|------|
| `lab01` | Основы Python, первый Django-проект |
| `lab02` | HTML-шаблоны и CSS |
| `lab03` | Модель статей и админка |
| `lab04` | Страница одной записи |
| `lab05` | Форма добавления поста |
| `lab06` | Регистрация и вход |
| `lab07` | JavaScript: консоль и DOM |

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Дальше — инструкции в README внутри каждого `lab0N`.
