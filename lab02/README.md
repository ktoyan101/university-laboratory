# Lab 02 — страница и статика

Проект `firstwebpage`, приложение `flatpages`.

## Дерево

```
lab02
└── firstwebpage
    ├── manage.py
    ├── firstwebpage/     # настройки проекта
    └── flatpages/        # views, templates, static
```

## Как запустить

```bash
cd lab02/firstwebpage
python3 manage.py migrate
python3 manage.py runserver
```

Откройте `/` и `/hello/`.
